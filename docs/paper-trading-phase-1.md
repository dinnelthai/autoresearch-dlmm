# Paper Trading P03–P07 bounded MVP
Read-only runner consumes a cumulative normalized event file with the existing T11 sample structure (reviewed declared coverage, MARKET/POOL_STATE/SWAP/LIQUIDITY_UPDATE). No data provider is called. Each strategy has its own virtual wallet, position bins, accrued fees and logical operations; identical initial capital. Eight modes: HODL/no LP, Spot, Curve, Bid-Ask, Hybrid, Asymmetric, fixed Hybrid Grid midpoint comparator, and Adaptive. Existing T09/T10 and engine math are reused. Static comparators attempt once, Adaptive re-evaluates. A pending virtual intent is not a confirmed operation. No implicit spot conversion or disposal. Existing shadow replay defaults unchanged.
Use config example only as an intentionally invalid template; set actual pool/mints/start, positive capital and all explicit Engine.DEFAULTS parameters for actual pool (binStepBps and anchorPrice especially; no demo default assumption). `node research/live/paper-run.mjs --config data/paper/config.json --sample data/paper/sample.json`; optional `--watch --interval 30` polls the supplied local file (producer should replace atomically). Output: data/paper/<id>/checkpoint.json. Prefix hashes and backend source fingerprint prevent changed history or changed code from silently continuing. Each new sample must include the entire previous prefix and strictly later events; maximum 5000 events. Recomputes from beginning, not an unbounded incremental engine; pending intent carries through deterministic replay. Evidence verified by file hashes and existing structural contract, not independent semantic review. A failure leaves previous checkpoint explicitly stale; do not use it as current. No automatic deletion; exclusive writer lock, inspect process before removing stale lock. No live profit claim. 
Current limitations: no automatic real-chain producer/normalizer, no UI report view yet, no protocol-exact counterfactual simulation or verified fee allocation. Existing capture-swaps output is aggregate and MUST NOT be relabeled per-bin. P01/P02 are blocking actual mainnet operation. P03–P06 first implementation, P07 bounded replay/checkpoint, P08 pending. Native Node and real data acceptance pending. Run node --test research/live/paper-core.test.mjs and full verifier.
