# Dynamic LP 算法原理与数学优化路线

> 2026-11-27 · 代码依据：ffd862716af36117da166e44060afd1e1450ab25  
> 本文描述当前 JS Adaptive Paper 的业务与数学实现，并将后续研究方向单独列出。它不是盈利证明或实盘验收报告。现阶段优先让真实数据驱动的单一策略持续运行；不因本路线扩展联调范围。

## 1. 核心业务目标

Dynamic LP 是动态流动性资产配置问题，不是普通 K 线方向交易。对用户指定、流动性良好的 Meteora 池，在给定虚拟 SOL/MEME 本金与风险预算下，每次市场更新决定：是否提供流动性、投入多少、在哪些 Bin 投入、每个 Bin 权重、是否持有/减仓/调仓/撤出。目标为提高相对原始资产持有（HODL）的风险调整后净收益。NO_LP 是内部机会成本基准，不是第二套实验策略。Spot、Curve、Bid-Ask、Hybrid、Asymmetric、Hybrid Grid 是同一策略的内部候选。

主循环：真实目标池快照 → 市场环境识别 → 准入与资金预算 → 候选分布 → 未来行情情景评估 → 效用排序 → 整数份额映射与虚拟执行 → 观察手续费、库存、NAV → 下一次快照重复计算。无真实资金、签名或链上提交。

## 2. 一根 K 线与实际输入

网页 Meteora 1h OHLC 是展示数据（价格单位仍标记 PROVIDER_UNIT_UNVERIFIED），不直接输入当前 JS 策略。旧 Python OHLC 研究独立，不能混入 JS Paper 账本。当前每个真实池快照包含 Slot、时间、Active Bin、Bin Step、Bin 价格、X/Y 库存、流动性份额、累计手续费增长；成交窗口与 Holder/外部参考池为可选增强。X 为 MEME、Y 为 SOL 的当前支持方向。

目标池 Active Bin 原始 Q64 价格转换为人类单位：P = (priceQ64Raw / 2^64) × 10^(decimalsX − decimalsY)。Paper 使用目标池自身价格作定位及估值标记，不称独立公允价格。退出深度为当前 Bin 向低价方向连续 200 bps 范围内实际 SOL 库存的毛额代理，不是可执行报价。外部参考不再是启动前置条件。缺失成交量不虚构预测手续费；缺失 Holder 等标记 null，增加不确定性门槛。当前快照必须真实、有效；无未来信息泄漏。

如果将来引入 OHLC，O/H/L/C/V 只提供区间摘要；同一 OHLC 可能对应不同盘中路径与跨 Bin 成交，不能单独重建 LP 手续费或仓位变化。应使用真实快照/成交序列计算已观察收益。

## 3. M01 市场识别与 M02 准入

对最近 n 个快照价格 P_t：

- 对数收益 r_t = ln(P_t / P_(t−1))
- 趋势 T = Σ r_t
- 路径波动 V = sqrt(Σ r_t²)（未年化、未做固定时间归一化）
- 趋势效率 E = |Σ r_t| / Σ|r_t|；路径为零时 E = 0。

默认 regimeLookback=12，regimeMinObservations=3，趋势效率门槛 0.65，趋势累计对数收益阈值 ±0.025，单步压力下跌阈值 −0.20。结合退出深度、已知代币风险、成交活跃度、Holder 集中度、Holder 流出与买卖失衡。当前默认值不是已校准最优值。

| 状态 | 当前逻辑 |
|---|---|
| HEALTHY_RANGE | 允许评估双侧或单侧候选，不保证部署 |
| UPTREND | 允许候选，非对称方案改变 Ask 比例 |
| DOWNTREND | 候选 Bid 预算为零，已有 MEME 可用于 Ask |
| DISTRIBUTION_RANGE | 不新增 LP；考虑保护性动作 |
| DEAD_RANGE | 已观测低成交活跃度，不新增 LP |
| STRESS | 已知代币风险、低退出深度或压力下跌，考虑减少/撤出 |
| UNKNOWN | 非 Paper 严格路径或无有效价格；不能冒充健康行情 |

Paper 缺失增强输入或样本不足时可能暂列 HEALTHY_RANGE，同时带 REGIME_WARMUP_PROVISIONAL 等诊断；不是证明市场健康。已知集中度超限仍拒绝准入。Markout 毒性模型存在于规范化成交引擎，但当前快照 Paper 无实测可归因 Markout，不应宣称已校准。代码：research/engine/market.mjs。

## 4. M07 库存风险与资金预算

设当前可用与已部署及待领取合计资产为 X、Y；每个 Bid Bin 有 SOL y_i，价格 p_i，标记价 P。假设所有 Bid 转化为 MEME，则最坏库存 X_post = X + Σ(y_i/p_i)，Y_post = Y − Σy_i；库存比例 R_post = X_post P / (X_post P + Y_post)，分母为零时按代码置零。

压力价 P_s=P(1−stressDrop)，压力资产值 V_s = X P_s + Y − Σ[y_i max(0,1−P_s/p_i)]。压力损失 L=max(0,NAV−V_s,初始NAV+外部净资金流−V_s)。退出深度约束基于标记名义价值代理。

对候选单位 SOL 权重 w_i，计算 q=Σw_i/p_i，h=Σw_i max(0,1−P_s/p_i)，库存比例上限 ρ。可新增 Bid 预算取以下限制最小值后截断为非负：
- 钱包 SOL − 最小储备；
- (最大库存数量 − X_post)/q；
- [ρ(X_post P+Y_post)−X_post P]/[(1−ρ)qP+ρ]；
- 退出深度剩余名义容量/(qP)；
- (最大压力亏损 − L)/h（h>0 时）。

已有风险超限或 NAV 无效则不增加 Bid。每种 Bin 形状按其自己的单位权重计算预算，而不是统一按当前价格近似。Ask 使用已有钱包 MEME 的候选比例；Paper 主流程不主动购买初始 MEME，不主动现货卖出。仅 SOL 本金遇到下跌状态时可能没有可行开仓。代码：risk.mjs、liquidity.mjs。

## 5. M03–M06 候选资金分布

Bin 价格 p_i = anchorPrice × (1+binStepBps/10000)^i；目标价对应 Bin 通过对数求最近整数。当前快照 Active Bin 与模型定位必须一致。对距 Active Bin 第 j 档，j=1..n：

- Spot：均匀 1/n。
- Curve：exp(−3(j/n)^2)，集中近端。
- Bid-Ask：0.1+(j/n)^2，偏远端。
- Hybrid：α/n+(1−α)×归一化 Bid-Ask。
- Asymmetric：使用 Hybrid，Bid/Ask 的 α、skew 不同；skew 通过 exp(skew×j/n) 调节。
- 所有权重最终归一化；Ask 侧再按对应价格换算 Token 数量，使资金价值权重有意义。

基础五种形状 × 每侧宽度 {2,4,8} × 资金系数 {0.5,1} = 30 个候选；Hybrid Grid 再搜索 α_bid、α_ask ∈ {0,0.25,0.5,0.75,1} 的 25 个组合，宽度固定 4。空仓 Paper 共 55 个部署候选加 NO_LP；已有仓位还包含 HOLD、REDUCE（当前 50%）、REMOVE_AND_HOLD。部分形状有 Active Bin 资金份额（Spot 0.1、Curve 0.2），但混合资产整数映射可能拒绝不成比例的存款。真实可行候选数不等于枚举数。

候选经过实际已观察 Bin、份额、钱包、风险及整数映射预检，映射后的本金、余额、成本进入同一个预测模型再评分。当前比例份额只是 Paper 代理，非协议精确 mint 公式。代码：decision.mjs、liquidity.mjs、preview-plans.mjs、preview-management.mjs、paper-share-core.mjs、paper-adaptive-core.mjs。

## 6. 未来市场路径与手续费预测

当前 forecast.mjs 采用五种确定性情景等权评估，不是训练好的概率预测。默认预测 480 秒、8 步，可受请求参数覆盖。以当前 Bin 为中心，步号 i：
- range：round(A sin(iπ/2))，叠加趋势 drift×i；
- up：+i；
- down：−i；
- whipsaw：前半 +i，后半 −i；
- stress：−round(iA/2)。

A=clip(round((V 或默认 0.02)/ln(1+s)),2,8)，s 为 Bin Step 比例；drift 按上涨/下跌取 +1/−1，否则 0，当前仅叠加到 range 路径。注意代码零波动也走默认 0.02。路径等权并不意味着真实市场概率相等。

近期观察窗口 W 内成交额 F 已知时，每步预测成交额 = F/W × 步长秒数。缺失成交量时不生成虚构费用；冻结当前 Bin 流动性作为未来份额代理，只模拟路径端点成交，不推断跨越的每个 Bin 都成交。手续费基于配置费率、协议分成及模拟参与份额计算。未观察 Bin 及成交覆盖缺口保留诊断。情景收益不是已观察手续费。

## 7. 最核心：风险调整效用函数

对候选动作 a，在各情景中计算相对原始资产基准的增量 Alpha、费用、成本、库存比例和路径亏损。当前公式：

U(a) = mean(ΔAlpha) − λ CVaR_β(L_path) − κ mean[(R_terminal−R_target)^2]

ΔAlpha 是相对于当前仓位在同终点价格的增量超额收益；操作成本已经进入净值，不能重复扣减。L_path 为相对情景初始 NAV 的最大路径亏损，不等同于连续峰谷回撤；另外记录终点 CVaR 与最大回撤。CVaR 使用有限情景加权尾均值；五条等权路径、β=0.95 时基本由最坏样本决定，不能称统计校准的 95% 尾风险。

默认 λ=0.5，κ=0.2 SOL，目标库存比 0.45，β=0.95；目标和风险参数可覆盖。选择可行候选中效用最大者，并且优于 NO_LP/HOLD 的差值须严格超过 minImprovementSol + uncertaintySol（实际参考置信度/缺失数据会扩大门槛）。两项基础默认各 0.005 SOL；目标池低置信度乘 2，缺失增强或未充分预热时再乘 1.5，系数未校准。调仓还要求相对 HOLD 的预期净收益优势，受到冷却时间、调仓次数、周转预算约束。

数学意义：收益、风险、库存及执行成本联合比较，而不是单纯寻找最高 APR。没有优势时 HOLD/NO_LP 是合法动作，不能为了联调强制开仓。代码：evaluation.mjs、decision.mjs。

## 8. 真实快照驱动的 Paper 账本

持仓运行后，每次新快照根据虚拟份额与观察到的 Bin 库存/流动性供给估算本金 X/Y 转换；根据累计 Q64 fee growth 差计算费用。当前手续费代理对增加虚拟份额造成的稀释使用两端供给中点修正，具体整数累积与舍入见 paper-fee-core.mjs。费用没有实测增长时不得把预测费用加入实际 Paper 收益。

NAV = 钱包资产 + LP 本金 + 待领取手续费的 SOL 标记价值；已领取费用已经进入钱包，不重复加；操作成本已经扣自钱包。无额外资金流的实验 PnL = NAV−初始NAV；HODL = 初始X×当前P+初始Y；Alpha = NAV−HODL。正手续费并不等于正净收益。调仓释放本金、处理待领取费用并记录成本，原始本金基准保持不变。当前虚拟执行仍需后续真实快照确认动作和时间顺序（默认意图延迟 10 秒），不等于即时成交或真实交易。

每次观察记录市场、候选、选择/拒绝原因、动作及账本；继续运行即可积累证据，不必等待实验结束。联调看 docs/codex-dynamic-main-flow.md，导出日志见 README。

## 9. 后续数学优化路线（待研究，非当前联调任务）

先实现并观察当前单一策略的真实业务闭环；之后按优先级研究，不新增并行策略、数据库或数据供应商。每项修改必须使用相同输入比较旧/新算法，并按时间划分训练/验证，避免未来数据泄漏和重复调参污染验证集。

| 编号 | 优先级 | 优化方向 | 现有局限与研究方案 | 验收指标 |
|---|---|---|---|---|
| O01 | P0 | 市场路径概率模型 | 五条固定等权路径缺乏概率校准；先按市场状态对真实快照收益及波动分布进行分组，考虑经验重采样与条件情景权重，保留压力情景 | 样本外分布覆盖、分位数校准、预测误差、净 Alpha/CVaR |
| O02 | P0 | 多时间尺度市场识别 | 快照间隔不固定、单窗口趋势易误判；利用因果历史构造时间归一化收益/波动、趋势效率、多周期特征；K 线单位须先核对 | 状态稳定性、切换频率、各状态实际 Alpha；缺失数据时可降级 |
| O03 | P0 | 成交与价格联合预测 | 固定窗口线性外推忽略方向、波动与成交关系；估计条件成交额与方向，按路径分配交易量，不填补不可观测成交 | 成交量样本外误差、手续费预测偏差、覆盖率 |
| O04 | P1 | Bin 分配优化 | 55 个离散候选，宽度及权重有限；先对现有网格参数敏感性研究，必要时扩展连续权重/局部搜索，整数映射后再评分 | 相同风险预算的样本外效用提升、资金利用率、计算时间 |
| O05 | P1 | 动态流动性与手续费预测 | 当前冻结 Bin 流动性、配置费率；利用真实观察的流动性及费率变化建立条件预测，区分协议事实和策略假设 | 预测/观察费用偏差、有效参与率、费用归因 |
| O06 | P1 | 调仓经济价值 | 固定改善门槛、冷却、候选减仓比例；研究预期增量净收益与操作成本、库存风险、预测不确定性的动态关系 | 净 Alpha、调仓成本占比、周转、回撤；不以动作次数为成功 |
| O07 | P2 | 逆向选择与置信度 | Markout 缺少成交级证据；先研究可归因真实成交数据是否可得、区分主动买卖与 LP 资产转换，再研究动态风险惩罚；不伪造 Markout | 成交后价格偏移、分侧费用净收益、置信度与实际误差关系 |
| O08 | P2 | 参数校准与稳健性 | 当前参数未校准；按 m12-parameter-reachability.md 核对参数生效，再分市场状态进行滚动样本外验证和敏感性分析 | 净收益、HODL Alpha、CVaR/回撤、稳定性、费用/成本、覆盖率 |

推荐顺序 O01–O03 优先（预测决定最优解是否有意义），随后 O04–O06，最后 O07–O08；参数可达性审计贯穿研究，但不阻塞当前运行。所有性能结果均需记录池、时间窗、版本、配置、风险与本金、缺失数据、实际部署及成本。没有真实数据支持时仅报告假设或离线结果，不保证盈利。不能用模型预测的费用替代快照账本，也不能把暂时无仓位当作已完成开仓验收。
