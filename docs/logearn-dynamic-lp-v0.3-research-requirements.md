# LogEarn Dynamic LP v0.3 — 数学推演、数据模型与产品需求

日期：2026-11-25；状态：研究设计草案，待数据验证与需求评审。仅文档，不开发代码、不改变回测器、不发送交易。承接 v0.1（2026-11-22《数据模型与项目设计方案》）及同仓库 [v0.2](logearn-dynamic-lp-v0.2-markout-mev-defense.md)。v0.2 的净值、逐笔 Markout、数据质量、对照验证约束继续有效。本文新增公式、参数网格及功能边界为研究提案，非盈利结论。目标：给 Meme 二段交易用户提供风险受控的额外收益；仅现货、Meteora DLMM、SOL 计价，排除衍生品、操纵交易及生产签名。

## 1. 研究问题与需求边界

M01 选币选池：识别流动性、可退出性、筹码集中、持续派发风险；先比较固定准入与筹码辅助准入。
M02 入场：区分健康盘整、派发盘整、死亡盘整、趋势及异常；Range LP 为二段研究主线，Launch LP 另立样本与基准。
M03 分布：Spot / Curve / Bid-Ask / 非对称与 Hybrid；研究模板、两侧资金预算、区间与权重。50/50 不是先验最优。
M04 库存：Ask 优先、SOL 储备、MEME 风险预算；价格下跌不自动补 Bid。
M05 调仓：净边际改善、逆向选择防御、执行延迟与成本；可选择不操作。
M06 退出：降敞口、撤池及独立现货处置；无深度不能假定已退出。

不以 APR、交易量、在区间时间作为单一目标。选择 NO_LP 是有效结果。产品初版不是全天候盈利工具，不提供保本承诺。

## 2. 统一资产与盈亏恒等式

P 为 SOL/MEME；x,y 为钱包、LP 本金与已经赚得费用合并库存（费用不能重复计入），V=xP+y+其他净资产。无外部流入流出时，对按链上事件排序的离散账本：

ΔV_k = x_(k-1) ΔP_k + P_k Δx_k + Δy_k。

剔除内部转移后，把余额变动拆为带符号成交 q（买正卖负）、无单列费用的成交价 e、实际 LP 费 f、真实单列成本 c、外部现金流 d。则 ΔV = x_prev ΔP + q(P-e)+f-c+d（其他资产变动独立列账）。终点净 PnL = V_T-V_0-Σd。相对于初始同库存 HODL 的 Alpha，在无资金流情况下：

Alpha_H = Σ[(x_prev-x_0)ΔP + q(P-e)+f-c]。

绝对 SOL 盈利与超额 HODL 盈利分别呈现。示例：本金 10 SOL，初始 5 SOL + 50 MEME（P0=0.1）。P_T=0.05 时 HODL=7.5 SOL。策略终值 8 SOL 则 Alpha_H=+0.5 SOL，绝对 PnL=-2 SOL。不能称为保本。若只有一个市场、估值源不可信，则报告 NAV 估值质量，压力测试另外给出可执行清算价值，不能用无深度的边际价保证本金。

IL 是相对基准的差值；Markout 是成交后诊断；LVR 是相对参考价执行库存变化的模型损失；防御贡献是开关消融的净差。四者有重叠，不可叠加成额外现金流。保留 v0.2 归因方程。

## 3. 库存风险推演（M04）

以两资产简化模型定义 z=xP/V（MEME 市值占比），z∈[0,1]；费用、其他资产和负债按真实可提取性修正风险口径。z* 为当前风险容许目标，不是永远 50%。在不改变报价价格的单次交易近似下，若 LP 买入名义金额 n（SOL），忽略费用且按 P 成交，xP 增加 n、y 减少 n、V 不变，z_new=z+n/V。LP 卖出则相反。故目标前的可新增 Bid 名义预算：

B_cap=max(0,min(y_available-S_min,(z_max-z)V))。

这里是单价、无费用、无其他订单的初步上界，而不是协议报价或真实最大部署量。实际需使用预计每个 Bin 可成交数量、手续费、所有未撤已部署 Bid 和在途决策、跳空及延迟，在多个压力路径上重算库存与 SOL 余额；避免重复承诺。若当前 z>z_max，禁止新增 Bid，按可执行性 REDUCE / REMOVE 并评估现货卖出。仅撤池不会减少 MEME 库存风险。

举例：NAV=10 SOL，MEME=3 SOL，SOL=7，z_max=40%，最低 SOL 储备=2 SOL，则当前参考价下新增 Bid 总暴露上界为 1 SOL，而不是余额减储备得到的 5 SOL。若现有可成交 Bid 已占 0.8 SOL，剩余增量预算至多 0.2 SOL，尚需压力测试。以上数字只用于推导，不是生产风控阈值。

价格变动亦改变 z：仅盯市时 z(P')=xP'/(y+xP')；价格跌落可能使 z 比例变小，但绝对损失和可接盘风险反而变大。因此额外限制已承诺 Bid 的 SOL、MEME 数量上限、压力路径最大损失和清算深度，不使用 z 单指标。上涨期间 Ask 卖光的机会成本用 HODL 比较，保留库存上限优先。

## 4. 成交质量、报价与调仓决策（M03/M05）

沿用 v0.2：M_i(h)=q_i(P_ref(t+h)-e_i)+f_i，使用 SOL 价值；净 Markout 的费只含己方实际归属，操作成本另列。对所有有效成交保留正负符号，分别计算 Bid/Ask 的 E[M|state]、名义金额加权 bps、尾部损失与覆盖率。事后标签只能在成熟且到达后用于决策。

候选动作 a∈{HOLD,REPOSITION,REDUCE,REMOVE,NO_LP}；一个控制周期 H 内的统一目标为
J(a|s)=E[Alpha_HODL(a)|s] - λ CVaR_β(L(a)|s) - κ E[(z_end-z*)²|s]。
Alpha 使用 SOL；CVaR 为 SOL 损失的尾部平均；λ 无量纲，κ 为 SOL，禁止把无量纲比例与 SOL 直接相加。L 预先定义为绝对资本损失（非相对持币损失），确保下跌市场即使跑赢 HODL 也受约束。策略侧风险限制包括所有在途指令、最小储备、最大风险预算、可退出深度、数据质量。λ、κ、β 待校准。

候选边际近似：E[Σ net_markout at one fixed h] - 增量操作成本，只用于成交质量代理及局部策略筛选，不代替完整终点 Alpha；不同期限 Markout 不相加，不能再加同一批 Fee 或扣同一批 Toxicity。库存变化引起的后续风险由全路径估值和风险项处理。无足够成熟成交时标记 UNKNOWN，不默认零毒性。

调仓准则：ΔJ=J(REPOSITION)-J(HOLD)。在两动作都满足硬约束时，只有 ΔJ 高于模型不确定性缓冲且执行窗口可用，才进行普通调仓。成本与少赚的手续费在各自情景 J 内比较，不二次扣减。安全退出不等待收益阈值。引入实际延迟、失败概率、撤池前可能成交的数量；确认回执之前按原仓位暴露计算。静态、无防御、主动防御必须使用同一延迟与成本假设。

假设防御少赚 0.02 SOL 手续费、节约不利成交损失 0.07 SOL、额外操作成本 0.01 SOL，其他条件相同，则理论增益 0.04 SOL。避免的损失不是独立收入；若漏掉后续有利成交或市场跳空，实际差值可能为负。仅为算例。

### 4.1 混合分布预算

候选模板的各侧权重分别归一化；u_i^Spot 与 u_i^BA 非负，各自对该侧求和为 1。对已确认可部署的一侧预算 B：
w_i(α)=α u_i^Spot+(1-α)u_i^BA，b_i=B w_i(α)。
Bid、Ask 可有不同 α 与预算；Bid 用 SOL 单位，Ask 用 MEME 单位；转为协议 Liquidity 单位前验证 decimals、Token 顺序、Active Bin 的双资产规则。空侧不凭空生成资产；资本比例以独立 P 折算。测试 α∈{0,.25,.5,.75,1}，先固定，再按状态自适应；不预设结果。仓位小且分布变化可忽略市场影响时只允许筛选，最终验收需建模自身深度影响。

### 4.2 有毒订单流与参考价

来源须独立于目标池直接报价，检查可执行深度、时间戳/到达时间、跨源偏差。多池或路由独立性需实证，若引用路由实际经过目标池则不独立。独立参考价缺失的单池 Meme 不声称能准确识别套利。允许普通市场波动、套利与未知流分类，不能仅因负 Markout 判定 MEV。保护己方仓位，不攻击他人交易或操纵交易顺序。

## 5. 数据模型（逻辑设计，不确定数据库实现）

层次 A 原始事实（不可覆盖）：pool_account_snapshot / bin_snapshot / swap_event / liquidity_event / fee_event / price_observation / token_holder_snapshot / token_transfer_event。保存 raw integer、mint、decimals、slot、tx/ix/event index、来源、event_time、available_at、parser_version、hash。价格和筹码事件区分 observed_at 与可获得时间，按当时所知构建，不使用事后已知钱包标签或未来榜单。

层次 B 状态重建：pool_state、bin_state（每个 bin 两资产储备、总流动性、己方份额、费用、active_bin）、position_state、inventory_state、market_state。每份状态包含 asof key、版本、数据覆盖和置信度；链上 slot 顺序可重建且通过快照对账。

层次 C 特征与标签分离：feature_snapshot（价格偏差、成交方向与强度、波动、深度、筹码集中及净流、库存和已成熟 Markout）、fill_markout（1/5/30/60s）、regime_label（事后标注用于评估，不得进入在线特征）。特征须有 available_at≤decision_time；缺失不填零，记录 reason，单池无独立价格时 markout invalid。

层次 D 决策与反事实：strategy_config、risk_budget、candidate_action、risk_decision、paper_execution_receipt、position_lifecycle。候选动作保存预测及约束结果、选择理由；receipt 保存失败、确认及余额变化。反事实回放按相同原始事件与冻结假设分 run，不能将两组仓位混入一个账本。

层次 E 结果：lp_fill（己方每 Bin 成交）、pnl_attribution、nav_snapshot、experiment_run、backtest_metric、data_quality_report。每条衍生记录可回溯到来源事件和 run_id，唯一键防重。NAV 同时报告 mark-to-market 及压力情景下可清算价值，后者非已实现收入。

| 数据需求 | 最小时间粒度 | 缺失后的限制 | 优先级 |
|---|---|---|---|
| Pool/Bin 初始状态 + 完整变动 | slot + tx/ix/event | 不能证明 LP 份额与回放 | P0 |
| Swap 与手续费分配 | 逐笔/逐 Bin | 不能计算真实成交与费用 | P0 |
| 独立价格及深度 | 足以覆盖标注期限；记录可用时间 | 不可测相关期限 Markout 或套利风险 | P0 |
| 退出可执行报价/网络延迟与成本 | 按决策窗口 | 不可声称实际能及时退出 | P0 |
| 筹码/大户与转账数据 | 事件或有时效声明的快照 | 不可验证筹码增量价值 | P1 |
| OHLCV、成交量与波动 | 分钟或更细 | 仅粗筛与状态先验 | P1 |

原始历史数据来源仍需审计，Meteora/SDK、RPC、Bitquery 免费样本与独立市场报价为候选，不预设历史 Bin 可取得。不购买未验证数据。MVP 存储形式可用 Parquet/DuckDB，非本阶段开发要求。

## 6. 功能需求（仅产品与策略规格）

| ID | 需求 | 输出 | 验收 |
|---|---|---|---|
| FR01 P0 | Token/Pool 准入与风险筛查 | 允许/拒绝/未知及理由 | 缺数据不默认为安全；无退出路径禁止新增敞口 |
| FR02 P0 | 库存与风险预算 | 可部署 SOL/MEME、承诺 Bid、目标库存 | 无超配、无负余额，压力路径风险有明确状态 |
| FR03 P0 | LP 分布与策略比较 | 模板、两侧预算、Bin 权重、对照组 | 资本守恒，方向精度正确 |
| FR04 P0 | 逐笔费用及 Markout | Bid/Ask 质量、覆盖率、净费 | 已成熟标签，无重复费用、无伪造参考价 |
| FR05 P0 | 风险动作与退出 | HOLD/REPOSITION/REDUCE/REMOVE/NO_LP、独立处置建议 | 硬约束优先；撤池与卖出分开；未确认不算成功 |
| FR06 P0 | 收益与复盘 | NAV、HODL、SOL 基准、成本、归因、风险、数据质量 | 账本守恒；绝对/相对收益区分 |

产品页面概念：研究总览（净收益、风险、数据置信度）→ Token/Pool 研究 → LP 策略方案（两侧、预算、预期区间与压力情景）→ 仿真与账本复盘。只读/虚拟资金，不做交易按钮、钱包签名、权限架构或代码开发。UI 不是当前交付目标。

## 7. 实验与决策门槛

E0 账本与数据质量：合并资产对账、顺序与幂等、两方向价格、缺失及重复事件、费用只入账一次；失败则停止下游结论。
E1 静态基准：HODL、全 SOL、Spot、Curve、Bid-Ask，同初始资产、真实成本、统一事件路径。
E2 Hybrid：固定比例网格、非对称、按状态动态比例；先排除参数过拟合。
E3 库存：同一分布，仅切换库存约束与 Ask 优先；比较净 Alpha、MEME 峰值、最坏可清算价值、SOL 耗尽率。
E4 防御：同一策略仅切换 Markout/逆向选择风控；比较净收益差、少赚费用、操作成本、执行延迟、失败率与尾部损失。
E5 筹码：相同市场特征有/无筹码；记录入选与拒绝的完整样本；避免以事后成功币选样。
E6 联合方案：跨 Token、生命周期、不同市场状态；训练/验证/冻结测试按时间分离，边界隔离标签期限与持仓重叠；使用池/时间分组估计不确定性；压力测试跳空、无报价、网络延迟、退出失败、高费用。

研究门槛：数据充分且可对账；样本外相对基准经济改善为正并覆盖成本与估计不确定性；绝对亏损风险、最大回撤、CVaR、最坏窗口及库存约束在预登记风险预算内。阈值数值、样本量、持有时长、目标覆盖率、最大可接受回撤及最低净收益未由用户确定，不能声称通过。风险与收益证据冲突时保守选择 NO_LP 或更简单基准；数据不充分标记 INCONCLUSIVE。
