# S07/S08 candidate workflow
POST /api/terminal/research-build takes exact pool, marketSlot, marketRawHash and optional existing checked draft. Freezes the selected market state, collects block time (mainnet genesis, finalized slot and getBlockTime), existing holder capture and external quote capture in parallel, records source errors, saves the diagnostic snapshot and content-addressed candidate under data/research-candidates/<pool>/<candidateId>. A stale pinned market blocks saving; no latest-state substitution. Current archive pointers are not proof of chain authenticity; source time is not independently verified. The builder is on-demand and serialized against other capture/replay requests; no automatic unattended collection. The existing snapshot requires structurally matched review and evidence hashes before archiving review. If an explicit checked draft and matched review exist, reuse historical replay and existing seven-strategy model; otherwise return precise gaps. No model fields manufactured from partial holder, swap or quote diagnostics, no live binding, no transactions or readiness flags. Remaining core work: independently verified time/depth, full flow window coverage, holder outflow attribution, token safety and construction of reviewed observations; model cannot run on candidate alone. Source review files may be configured per pool. Run node --test research/live/evidence-builder.test.mjs research/live/research-snapshot.test.mjs research/live/terminal-http.test.mjs then full verifier. Local real RPC and model replay not performed here.
