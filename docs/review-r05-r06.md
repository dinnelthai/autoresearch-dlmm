# R05/R06 market feature diagnostics
The model-input endpoint now projects bounded swap observations, external quotes, and holder/mint facts. Holder capture is explicit via the terminal button, at most one request globally with a 60s cooldown; requires SOLANA_RPC_URL and mainnet genesis. It uses the classic SPL token program, mint filter, account layout checks, 16MiB/50k row cap, mint supply/authority reads before and after index, monotonic context slots and <=150 slot bracket. Top 10 concentration aggregates token accounts by owner, includes pool and custody accounts, and is suppressed unless observed balances conserve bracketed supply. This is not proof of complete indexing or a same-slot mint snapshot. Previous top cohort net balance decrease is not transfer or sell flow, and is not model holderOutflow. Prior snapshot is in-memory only (four scoped entries); raw RPCs and manifests archived locally. Token authority facts never assert tokenSafe. Unsupported tokens, RPC restrictions, oversized responses or missing history remain explicit gaps. No auto-review promotion; complete window flow, independent reference and review evidence still required.
