# P15–P17 auto snapshot experiments (primary pool MVP)
Terminal service uses existing reviewed draft preview + same raw market capture; starts one virtual experiment at a time for primary pool only. Explicit risk and exit cost parameters; no default values silently supplied. Server-local interval 15 s consumes latest available collector snapshot, re-decodes pinned raw captures, refuses same-slot hash conflict, old slots, pre-freeze requests, changed source code. Does not guarantee every intermediate snapshot captured; existing max gap and supply guards remain. No real wallet, signatures, blockchain writes or automatic trading. Persistent pointer and checkpoint under data/paper-auto/<pool>/<id>, exclusive file lock and atomic replacement; paused experiment preserved, new start creates another ID. Restart resumes an active pointer only with same code hash; pause does not redeem or resume, stop is server lifecycle. Existing HODL-only or unmapped LP experiment cannot start. Status API and browser polling show historical proxy marks and explicit freshness, not actual PnL. UI uses prepared strategy draft, existing independent review, and explicit risk inputs; no extra pool selection beyond main terminal. Current limitations: one active primary pool; no journal backlog replay, no exact protocol calibration, no adaptive rebalancing, no true continuous PnL. Source inventory requires restarting local service. Tests synthetic logic only; browser/native Node/RPC integration not verified.
