# External market diagnostics
DEX Screener token-pairs index discovers exact MEME/WSOL oriented pools other than the selected pool. Indexed price and liquidity are not independent reviewed executable depth. Raydium Trade API compute/swap-base-in is a public read-only quote endpoint; only single-hop routes matching a discovered Raydium pool and the exact input/output are accepted. Same-pool two-sided probes and a size ladder reuse quoteMath. No transaction endpoint or wallet address is used. Other venues and separate independent source verification are not implemented. No reviewed market artifact is generated automatically. Configure externalMarket.probeSolRaw/sellRaw/slippageBps/maxDiscountBps as diagnostic sizes only; defaults are 0.01 SOL and 1, 10, 100 token units, 50 bps slippage, 200 bps discount. Defaults may be too small, too large, or unsupported; the largest passing tested size is not total exit capacity. Raw replies and receipt time are archived locally; neither guarantees chain freshness. 
Official contracts: https://docs.dexscreener.com/api/reference and https://github.com/raydium-io/raydium-docs-v1/blob/main/sdk-api/trade-api.mdx. Run node --test research/live/external-market.test.mjs and verify actual responses on the configured host. No live API acceptance performed here.
