# Paper business gate policy

User decision 2026-11-27: prioritize the single Dynamic LP business flow. For automatic Paper only, holder completeness, holder cohort change, transaction history completeness, external reference count, and regime sample count are diagnostics, not startup gates. Current target capture drives every tick; optional enrichment is accepted only if already available and fresh. Missing values are null, never invented; forecast credits no hypothetical fees where volume is unavailable. Incomplete forecast bin coverage is recorded, not a blanket rejection. Warmup regime is provisional; unknown inputs increase uncertainty margin (initial multiplier 1.5, uncalibrated). Target Active Bin price is the placement/mark reference; external quotes remain optional evidence. Actual known concentration, token risk, low depth, capital limits, valid current capture, bin-side/quantity mapping and accounting invariants remain enforced. No real trades. Manual historical reviewed evidence remains strict and is not required for automatic Paper. No guarantee of opening when economic score is insufficient. Missing volume can materially reduce strategy quality; record this in reports. Verify new test paper-minimum-input.test.mjs and full primary path before declaring acceptance.
