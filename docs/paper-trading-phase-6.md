# Fixed-share snapshot experiment
Open a local frozen experiment with node research/live/paper-snapshot-run.mjs --id ID --snapshot data/raw/accounts-... --report data/research-report.json --policy data/paper/policy.json [--budget data/paper/budget.json]. Policy example is illustrative, not recommended parameters. The opening plan and raw capture must match; no later report/config can replace them. Update with same --id and --snapshot a later raw capture; optional --exit marks virtual withdrawal of all still-open strategies. Each update re-decodes opening, previous and new snapshots, checks source hashes, current code fingerprint, monotonic finalized slot and capture times, and only accepts requests after freeze. Exclusive writer, atomic checkpoint, bounded 1000 snapshots. Results under data/paper-snapshot-runs/<id>/checkpoint.json. No chain transaction, no automatic RPC, no wallet.
Observed-share scenario: principal = floor(virtual share * external bin principal / observed external supply); fees from opening-to-current Q64 checkpoint difference, never add each cumulative checkpoint or combine swap/diluted fees. This is a fixed observed-path attribution proxy, not added-liquidity counterfactual. Active-bin price is a raw Q64 mark (raw X to raw Y); all value fields Y lamports, no executable price claim. Cost reserves explicit; exit redeems modeled principal/fee and subtracts declared cost once, then holds tokens. Risk exits are same-observation accounting only. Changed/missing supply, stale gaps or regressed growth block affected paths permanently. Initial no-LP and unsupported plans retained; Adaptive selection is opening only, no dynamic rebalance. Capture timestamps are local declarations, no independent causality/coverage or PnL acceptance. CLI manual step; scheduled journal ingestion and UI still pending. Synthetic tests only; native Node and live data unverified.

Opening snapshot must also be within maxGapSeconds of the local freeze. Risk-loss virtual exit covered in synthetic regression. The risk check applies at sampled endpoints only, not between snapshots.
