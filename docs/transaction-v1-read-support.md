# Transaction V1 read-only compatibility
Source: https://solana.com/docs/rpc/json-structures and https://solana.com/docs/core/transactions/versioned-transactions. The raw JSON RPC collector now opts into version 1 for getTransaction and getBlock. A version-aware compiled-message normalizer distinguishes legacy, v0 ALT resolution and v1 static keys, checks indices and rejects unknown versions. No SDK upgrade or transaction construction is involved. The captured history remains bounded and unverified. Partial capture gap reasons remain visible; partial windows are not merged into accepted history or converted to zero volume. Existing archives that lack necessary version evidence can fail closed. Real v1 transaction / block / event acceptance requires a fresh sample and comparison with independent RPC/explorer observations. BinArray V2 position accounting stays blocked pending independent SDK amount and fee verification; matching common field layout is not evidence of accounting correctness.
